# 해원국립대학교 극시리 자캐커뮤니티 홈페이지

Astro로 제작된 정적 소개 홈페이지입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## GitHub Pages 배포

1. `astro.config.mjs`에서 `YOUR_GITHUB_ID`와 `base`를 저장소 이름에 맞게 수정합니다.
2. GitHub 저장소에 프로젝트를 업로드합니다.
3. Settings → Pages → Source에서 GitHub Actions를 선택합니다.
4. 포함된 워크플로가 자동으로 사이트를 배포합니다.
